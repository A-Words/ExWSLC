## 实现要求

1. 检查 AutoRefreshService、RuntimeWorkspace、窗口状态及日志跟随／统计调用。上游已增加空闲会话 VM 回收；先记录本项目周期查询是否会延长活动状态的证据，无法实测时明确标记推断。
2. 增加仅属于 ExWSLC 的刷新偏好，例如“窗口最小化时暂停自动刷新”，保持现有默认体验或提供明确默认值。区分窗口最小化与暂时失去焦点，不能因为用户切换到另一个应用就把界面状态长期停住。
3. 最小化时按所选策略暂停或降低后台清单／统计查询；恢复窗口后及时刷新。用户主动刷新始终可用，正在执行的任务、上传下载、构建和主动日志跟随不能被随意取消。
4. 清楚区分暂停刷新与停止容器／会话。本任务只调整应用请求调度，不调用 terminate／shutdown，不修改原生 WSL keep-alive 或 idle 设置，不承诺仅靠暂停轮询就一定回收 VM。
5. 处理刷新重入、窗口快速切换、任务完成后恢复、退出取消和订阅释放。必要时以小型可测试的调度状态表示，不把窗口细节散入运行时服务。
6. 在设置 UI 解释数据更新策略及显式日志跟随可能仍保持会话活动。只有真实测得的数据才能用于描述资源节省。
