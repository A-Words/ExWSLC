1. 在 ContainerCreateSpec 和容器创建 UI 中增加健康检查选项：继承镜像配置、显式禁用、自定义。自定义支持命令、间隔、超时、启动宽限期和重试次数，准确映射本机支持的 --health-*／--no-healthcheck 选项。

3. 解析新版容器列表 HealthStatus 和 Inspect 中实际提供的健康信息。在列表／详情中区分启动检查中、健康、不健康、未配置、未知；不要从 Running 状态推断应用已经健康。
