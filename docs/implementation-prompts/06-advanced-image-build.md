## 实现要求

1. 当前 BuildImageAsync 仅接收路径、标签、Dockerfile。将本任务所需配置集中为合适的构建请求，更新调用方、设计时实现和测试，保留现有简单构建流程。
2. 增加构建变量、目标阶段、禁用缓存、更新基础镜像，以及实际支持的 --secret、--output、--progress；如支持 --iidfile，可用于取得构建结果，但要管理本任务临时文件生命周期。
3. 输出模式至少覆盖当前 CLI 确认支持的本地镜像与本地目录／tar 产物。核对 Buildx 的输出语义：仅导出产物时不能假装创建了本地镜像，也不能强制要求无意义的镜像标签。
4. secret 使用 CLI 支持的文件／环境变量来源。不得把 secret 值塞进 --build-arg，也不得写入任务展示、日志或持久化设置；若为进程传递环境变量，只设置该子进程需要的值。
5. 在现有镜像页面增加折叠的高级选项，保持简单操作清晰。构建日志适配真实的进度模式并正确显示缓存步骤；不提供后端没有给出的百分比。
6. 保留任务取消、失败输出和成功后的资源刷新；导出文件路径、缓存等选项与镜像导入／加载表单互不污染。不引入完整 Buildx builder 管理。
