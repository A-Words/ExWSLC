## 实现要求

1. 在容器详情提供上传和下载入口，支持本地文件／目录到容器路径，以及容器文件／目录到本地路径。调用 wslc container cp，不用全容器导出来代替单路径复制。
2. 在 IContainerRuntime 后定义具有明确方向、容器 ID、本地路径、容器路径的请求；复用 IUserInteractionService 的文件／目录选择与现有任务、错误、取消机制。
3. 先核实当前 CLI 对目标已存在、目录内容复制、符号链接和 Windows 盘符路径的行为，只实现已确认的语义。路径含空格、中文、冒号或 shell 特殊字符时仍作为独立参数传递。
4. 开始前明确展示来源和目标；涉及目标文件覆盖时让用户确认并准确说明复制的覆盖语义。若 CLI 不提供百分比，只展示真实任务状态与可用输出，不伪造进度。
5. 用户切换所选容器后，已经发出的传输仍绑定原目标，取消能终止本任务进程。取消后不声称已回滚，也不删除可能由用户原先持有的目标文件。
6. 仅使用本任务拥有的临时文件或暂存目录并可靠清理。首版完成路径选择与双向复制，不扩大为远程文件管理器。
