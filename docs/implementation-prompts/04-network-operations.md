## 实现要求

1. 在 IContainerRuntime 后增加明确的连接／断开网络操作，在容器网络详情中提供入口，并复用已有网络清单。具体参数以 wslc network connect／disconnect --help 为准。
2. 连接时支持选网络、可选 IPv4、网络别名，以及运行时确实支持的端点驱动选项。用类型化请求和独立 ArgumentList 参数传递，不拼接 shell。
3. 完善网络创建的子网、网关、IP 范围参数，保留已有 driver options 与 labels。仅为实际可用的 CLI 参数提供可编辑项，避免重复或互相矛盾的映射。
4. 连接／断开完成后刷新相关网络、容器列表和所选容器详情，正确失效该容器的网络缓存。失败时保留有效详情并呈现错误，不把操作成功当成详情已刷新。
5. 断开操作沿用项目破坏性操作确认；并发点击、取消或切换容器时必须保持目标容器 ID 一致。已连接网络、非法地址、地址冲突和不支持的网络模式应有明确反馈。
6. 保留现有网络详情和端口暴露信息。本任务不实现网络编排，也不修改宿主机防火墙或现有用户网络。
