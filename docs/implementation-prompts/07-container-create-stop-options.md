## 实现要求

1. 扩展容器创建表单和 ContainerCreateSpec，增加已确认支持的镜像拉取策略 always／missing／never、停止信号和停止超时。未指定的选项保持运行时默认语义，不向旧版发送不支持的参数。

3. 停止接口变化需要核对手动停止、现有 stop → start 重启和导出时临时停止／恢复的所有调用方，不能遗漏恢复路径或更改自动删除容器的语义。
