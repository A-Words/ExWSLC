## 实现要求

1. 修复 WslcContainerRuntime 的列表与统计解析，覆盖旧 JSON 数组、现有受支持的数组包装对象、新版单个 JSON 对象、多行 JSON 对象，以及命令成功时的空输出。不要对 Inspect JSON 机械套用列表规则。
2. 上游 PR #41280 将容器、镜像、网络、卷列表和 stats 改成每行一个紧凑 JSON 对象；零条记录不输出内容。当前 ParseArrayPayload 只接受数组，ParseArray 吞掉 JsonException，网络路径则抛错并使 RuntimeWorkspace 整轮刷新失败。
3. 保留失败和空结果的区别：非零退出码、畸形 JSON、无效记录不能当成成功的空清单。混有损坏记录时报告可诊断的错误，不悄悄返回部分资源。刷新失败时保留上一次有效库存和明确的错误状态。
4. 核对当前实际输出中的 ID／Name、State、时间、Ports、网络和卷字段，保留已有正确的别名与端口格式兼容。列表中不再提供的字段不要编造，也不要为每次全量刷新增加不必要的逐资源 Inspect。
5. 新旧格式统一进入现有应用模型，不把版本分支传播到 ViewModel。不扩展健康检查或新操作；本任务只恢复已实现功能。
